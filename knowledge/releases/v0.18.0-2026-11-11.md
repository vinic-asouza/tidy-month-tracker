# Release Notes — v0.18.0

## SemVer

MINOR. Shell PWA instalável (online-first).

## Sumário da Release

O Finto passa a ser instalável como PWA no Chromium (manifest, ícones, service worker do app shell). Offline mostra aviso para reconectar — sem cache de dados financeiros. No iOS, o caminho continua “Adicionar à Tela de Início”.

## Destaques

- Web App Manifest + ícones 192/512 (maskable) + apple-touch-icon.
- Service worker com precache versionado (`autoUpdate`); Supabase em NetworkOnly.
- Banner “Sem conexão — reconecte para ver seus dados”.
